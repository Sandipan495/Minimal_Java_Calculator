# Minimal Java Console Calculator

A simple **console-based calculator** written in Java.  
It demonstrates the use of:
- Java `Scanner` class for input
- Loops (`while`)
- Modern **switch expressions** (Java 14+)
- Basic arithmetic operations

---

## 📌 Features
- Addition
- Subtraction
- Multiplication
- Division (handles divide by zero)
- Exit option to quit program
